Minimax Algorithm

Minimax is a recursive backtracking algorithm used in zero-sum, two-player games of perfect information. One player (MAX) aims to maximize the evaluation score, while the adversary (MIN) aims to minimize it. 

function MINIMAX(node, depth, isMaximizing):
    if depth == 0 or node is terminal:
        return EVALUATE(node)

    if isMaximizing:
        maxEval = -∞
        for child in node.children:
            eval = MINIMAX(child, depth - 1, FALSE)
            maxEval = max(maxEval, eval)
        return maxEval
    else:
        minEval = +∞
        for child in node.children:
            eval = MINIMAX(child, depth - 1, TRUE)
            minEval = min(minEval, eval)
        return minEval
Time Complexity: O(bd)
Space Complexity: O(b × d)
Alpha-Beta Pruning

Alpha-Beta pruning optimizes Minimax without altering the final decision. It maintains two thresholds: α (maximum lower bound) and β (minimum upper bound). If β ≤ α, the opponent can already force a worse outcome, so the remaining branches are safely discarded. 

function ALPHA_BETA(node, depth, α, β, isMaximizing):
    if depth == 0 or node is terminal:
        return EVALUATE(node)

    if isMaximizing:
        maxEval = -∞
        for child in node.children:
            eval = ALPHA_BETA(child, depth - 1, α, β, FALSE)
            maxEval = max(maxEval, eval)
            α = max(α, eval)
            if β ≤ α:
                break  // β cutoff (pruning)
        return maxEval
    else:
        minEval = +∞
        for child in node.children:
            eval = ALPHA_BETA(child, depth - 1, α, β, TRUE)
            minEval = min(minEval, eval)
            β = min(β, eval)
            if β ≤ α:
                break  // α cutoff (pruning)
        return minEval
Optimal Time Complexity: O(bd/2)
Move Ordering: Center column evaluated first for maximum pruning!

Connect Four Rules
  • Connect Four is played on a vertical grid of 7 columns and 6 rows (42 slots).
  • Players take turns dropping colored discs from the top into any unfilled column.
  • The disc falls straight down, occupying the lowest available slot within that column.
  • The first player to align four consecutive discs of their color horizontally, vertically, or diagonally wins immediately.
  • If all 42 slots fill without four in a row, the match ends in a draw.
Winning Strategies
  • Control the Center Column: Column 4 (index 3) is involved in up to 40% of all possible four-in-a-row winning lines. The AI evaluation assigns high priority to center column occupancy.
  • Plan Several Moves Ahead: Look for multi-threat opportunities where the opponent can only block one of two simultaneous threats.
  • Avoid Filling Columns Carelessly: Dropping a piece directly beneath an opponent's potential winning square gives them the victory on their next turn.
